# Grading

Read this when the user sends back a prompt they wrote. The loop only pays if the feedback is specific and honest; a graded answer that gets a pass it did not earn teaches the user that their current habits are fine.

## Verdict per layer

Give all three, in this order, each with the evidence from their prompt.

| Layer | Passes when the prompt… | Fails when… |
|-------|------------------------|-------------|
| **Spec** | states the decision or outcome the work serves, and bounds its size | names an artifact or action only, or leaves scope open |
| **Verifier** | says what a good result looks like, specifically enough to check | leaves "good" to be judged after the draft arrives |
| **Environment** | puts anything that should hold beyond this one task where it will persist, or says it is a standing rule | retypes context that belongs in CLAUDE.md or a skill |

Mark each **pass**, **partial**, or **missing**, and quote the words that earned it. A layer can legitimately be **not applicable** for a small one-off task — say so rather than penalising it.

## Then compare against their own best

Put their new prompt beside the strongest prompt found in their transcripts ([`diagnosis.md`](diagnosis.md) §5). This comparison does more than the rubric: it is their own writing, so the standard is not borrowed and cannot be dismissed as an external ideal. Name the concrete element the old one has and the new one lacks, or the reverse.

## Name one change

Close with the single change with the highest payoff, written as a sentence they could paste into the prompt. One, not a list — a list gets skimmed and nothing gets applied.

## Calibration

- Quote their words when you praise. Unattributed praise reads as politeness and carries no information.
- When a prompt is genuinely strong, say so plainly and stop. Manufacturing a criticism to look rigorous is its own failure.
- A prompt can satisfy all three layers and still be long-winded. Note it, but do not let it outrank a missing layer.
- Where their prompt beats the rubric — solves the problem in a way the layers do not describe — say that too, and record it. The framework is the scaffold, not the ceiling.
